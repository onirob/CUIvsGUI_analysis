# Data Availability

Participant-level data are not publicly available in this repository. The excluded materials include participant and platform identifiers, questionnaire responses, task-level records, event logs, chat messages, timestamps, demographic records, group assignments, participant-level derived datasets, and free-text responses.

The repository provides analysis code, aggregate statistical outputs, and figures. Descriptive/count tables containing any cell smaller than 10 were also withheld. No controlled-access promise is made by this repository; any future access arrangement would require separate review by the responsible data controller and the applicable ethics and data-protection procedures.
